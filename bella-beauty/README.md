# Bella Beauty — Sobrancelhas & Estética no Tatuapé

LP recriada a partir de https://sobrancelhasemsaopaulo.com.br/ no padrão das LPs de clientes (Vite + React + Tailwind v4).

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy na Vercel

Novo projeto a partir de `lp-clientes`, Root Directory `bella-beauty`, Framework **Vite**.
