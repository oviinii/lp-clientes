# Restaurante e Churrascaria da Nona — Aparecida/SP

LP no padrão das LPs de clientes (Vite + React + Tailwind v4).

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy na Vercel

Novo projeto a partir de `lp-clientes`, Root Directory `nona-churrascaria`, Framework **Vite**.
